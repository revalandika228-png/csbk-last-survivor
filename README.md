# CSBK Birthday Rhythm
A simple mobile-friendly rhythm game for the CSBK birthday event.

## Run locally
- Node.js 18+
- `npm install`
- `npm start`
- open `http://localhost:3000`

## Deploy on Railway
Deploy this folder as a new GitHub repository. Railway should detect `package.json` and run `npm start`.

## Notes
- The included song is `public/song.mp3` and lasts about 3:21.
- This first prototype has a simple generated note chart across the song; notes are not beat-mapped precisely to the recording yet.
- This version is a standalone rhythm-game prototype. Discord winner announcements and shared online leaderboard are not yet integrated.
