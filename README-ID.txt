CSBK LUCKY WHEEL — Birthday Fest 2026

UPLOAD KE GITHUB + RAILWAY (bisa dari HP)
1. Ekstrak ZIP ini.
2. Upload semua file/folder di dalamnya ke repository GitHub baru.
3. Railway: New Project > Deploy from GitHub Repo > pilih repo.
4. Tambahkan Variable: ADMIN_PIN = PIN_RAHASIA_KAMU (wajib ganti sebelum event).
5. Buka domain Railway dan bagikan link yang sama ke semua peserta.

ADMIN
- Login dengan ADMIN_PIN.
- Tambahkan setiap peserta: nama daftar + username Discord persis + tier.
- Tiket otomatis: Rookie 1, Hunter 2, Grinder 3, Investor 4, Elite 5, Sultan 6, Overlord 7.
- Jangan reset tiket kecuali ingin mengulang semua jatah.

PESERTA
- Masukkan username Discord dan nama yang sudah admin daftarkan.
- Centang pernyataan bahwa identitas milik sendiri, lalu verifikasi.
- Satu putaran mengurangi satu tiket. Semua penonton di link yang sama melihat animasi dan history live.

PENTING
- PIN default untuk percobaan adalah CSBK2026. Atur ADMIN_PIN di Railway sebelum acara.
- Hadiah Rp10.000 tetap terlihat pada roda, tetapi setelah dimenangkan server tidak memilihnya lagi. Agar tidak menyesatkan, halaman memberi tahu bahwa hadiah terbatas dapat habis selama event.
- Peluang yang ditampilkan adalah peluang awal; jika hadiah terbatas habis, peluang hadiah aktif dinormalisasi saat pengundian berikutnya.
- Musik custom disertakan di public/music.mp3. Browser biasanya baru mengizinkan musik setelah interaksi pengguna.
- data.json menyimpan data peserta dan history. Hosting dapat menghapus data saat redeploy/restart jika filesystem sementara; aktifkan persistent volume atau database untuk acara penting.
